# Terminology

See Section 3 of `SPEC.md`.

Additional terms:

- **Canonical form:** A deterministic representation used for comparison or hashing.
- **Pass-through mode:** Forwarding without semantic interpretation while preserving content.
- **Registry:** A governed collection of assigned identifiers.
- **Opaque value:** A value preserved without interpretation by Core.
- **Conformance vector:** Input and expected validation or canonicalization output.
