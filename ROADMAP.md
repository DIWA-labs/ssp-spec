# Roadmap

## Draft-00

- Publish problem statement and abstract model.
- Gather review on field boundaries.
- Validate examples in Python, Rust, and C#.
- Record unresolved canonicalization and registry questions.

## Draft-01

- Resolve canonical JSON rules.
- Add stable error identifiers.
- Add packet-size and parser-safety limits.
- Publish at least two independent interoperability reports.
- Decide media type and URI strategy.

## Draft-02

- Add signature and integrity profile or explicitly defer it.
- Finalize profile compatibility rules.
- Add binary encoding feasibility report.
- Prepare RFCXML rendering if an Internet-Draft is pursued.

## 1.0 candidate

- Freeze required fields.
- Freeze field meanings.
- Freeze canonical text representation.
- Publish conformance suite.
- Publish implementation reports.
